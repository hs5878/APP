## T13 · 사진 스캔 (SPEC F2 수용 기준)

목표: 5,000장 기준 1단계 묶음 10초 이내(중급 기기). 2단계 포함 전체 시간은 M3에서 기록.

측정 방법: `startScan(opts, onState)`의 `onState`에서 `stage1` 첫 호출, `stage2` 첫 호출, `done` 호출 시각을 `Date.now()`로 찍는다.
전체 스캔은 `forceFull: true`로, 디바이스 사진첩은 5,000장 이상, 그중 3장 이상 묶음에 드는 사진 비율을 같이 적는다.

|      |           |         |                |       |       |      | 미측정 |

## T18 · 사진 파일 암·복호화 (DATA_MODEL §5.1)

목표: 0.5MB 보관본 암·복호화 100ms 이내(파일 I/O 포함, 중급 기기).

측정 방법: dev build에서 설정 > 개발 > "암호 측정"(`src/crypto/benchmark.ts`의 `benchmarkPhotoCipher`). 512KB 무작위 파일로
① 파일 읽기(`File.bytes()`) + 암호화 + 파일 쓰기(임시 파일 → 이동), ② 파일 읽기 + 복호화 + 파일 쓰기를 10회 재고(첫 회 버림) 중앙값·최대를 적는다.
결과는 알림 창과 Metro 로그(`[T18]`)에 나온다. base64를 거치지 않는다.

| 날짜 | 기기 / OS | 암호화(I/O 포함) 중앙/최대 | 복호화(I/O 포함) 중앙/최대 | 암호화만 | 복호화만 | 비고 |
| ---- | --------- | -------------------------- | -------------------------- | -------- | -------- | ---- |
|      |           |                            |                            |          |          | 미측정 |

참고(기기 아님): 개발 PC Node v22 + wasm(libsodium-wrappers-sumo), 암·복호화만 512KB 20회 중앙 2.1ms / 2.0ms (2026-10-05).

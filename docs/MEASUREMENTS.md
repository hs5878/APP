# 실측 기록

## T13 · 사진 스캔 (SPEC F2 수용 기준)

목표: 5,000장 기준 1단계 묶음 10초 이내(중급 기기). 2단계 포함 전체 시간은 M3에서 기록.

측정 방법: `startScan(opts, onState)`의 `onState`에서 `stage1` 첫 호출, `stage2` 첫 호출, `done` 호출 시각을 `Date.now()`로 찍는다.
전체 스캔은 `forceFull: true`로, 디바이스 사진첩은 5,000장 이상, 그중 3장 이상 묶음에 드는 사진 비율을 같이 적는다.

| ---- | --------- | ------- | -------------- | ----- | ----- | ---- | ---- |
|      |           |         |                |       |       |      | 미측정 |

카톡 옛 사진 확인(수동): 스캔 1회 후, 촬영일이 한 달 전인 사진 3장 이상을 카톡에서 저장 → 앱 재실행 → 증분 스캔 후 후보에 잡히는지.
